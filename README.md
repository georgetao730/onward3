# Onward3

> **From Web2 Developer to Web3 Builder.**

Onward3 is an interactive Web3 learning platform built for Web2 developers who want to understand Web3 from first principles and learn by building.

## Why Onward3?

Web3 learning is often fragmented across documentation, videos, protocols, and tutorials. Onward3 turns that journey into a structured path with:

- **Web2 analogies** — understand unfamiliar Web3 concepts through familiar engineering mental models.
- **Visual explanations** — see how wallets, transactions, the EVM, and smart contracts actually work.
- **Interactive playgrounds** — learn by changing inputs and observing what happens.
- **Real projects** — move from concepts to working onchain applications.

## First Playground

**Wallet Playground** — visually explore the relationship between a private key, public key, Ethereum address, and transaction signatures.

## Product Principles

- Learn from first principles.
- Explain Web3 through a Web2 engineer's perspective.
- Prefer interactive understanding over passive reading.
- Learn by building real things.
- Ship early and improve in public.
